# Mizu v0.2.17

- 新增图标文件夹：在编辑模式拖动一个网站到另一个网站上，会自动创建文件夹。
- 文件夹使用两个网站图标组成预览，普通点击可打开文件夹浮层，背景仅做轻微模糊。
- 支持把网站拖入已有文件夹；从文件夹浮层拖到首页空白处，可将网站移回首页。
- 文件夹只剩一个网站时会自动还原为普通图标；文件夹可重命名或删除，删除时保留其中网站。
- 文件夹结构随备份导出与整体替换导入保留；合并导入时保留当前文件夹结构。

## 安装

1. 下载本页附件 `mizu-start-v0.2.17.zip` 并解压。
2. 打开 `chrome://extensions/`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `mizu-start` 文件夹。
4. 新开标签页。

已有安装可替换原目录文件并在扩展管理页刷新，本地数据会保留。
