# Mizu v0.2.15

首次开源发布，保留当前 0.2.15 版本号。

- 简洁的新标签页、内置壁纸与本地壁纸上传。
- 收藏编辑、长按拖动排序、在线与文字图标。
- 工具栏弹窗快速收藏当前网页，已打开的起始页实时同步。
- 多搜索引擎、浏览器历史搜索与本地设置保存。

## 安装

1. 下载本页附件 `mizu-start-v0.2.15.zip` 并解压。
2. 打开 `chrome://extensions/`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `mizu-start` 文件夹。
4. 新开标签页。

这是手动加载的 Chrome 扩展；后续升级需要替换原目录文件并在扩展管理页点击刷新。
