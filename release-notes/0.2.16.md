# Mizu v0.2.16

- 设置中新增备份导出与导入，可迁移收藏、图标、壁纸、顺序和全部配置。
- 导入时可在“整体替换”和“合并收藏”之间选择；合并会保留本机已有收藏。
- 导入成功后可在提示条中撤销，恢复导入前的数据。
- 备份为本地 JSON 文件，不上传到任何服务器，也不需要账号。
- 默认背景更新为浅色卧室企鹅玩偶壁纸，并适配浅色界面色调。

## 安装

1. 下载本页附件 `mizu-start-v0.2.16.zip` 并解压。
2. 打开 `chrome://extensions/`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `mizu-start` 文件夹。
4. 新开标签页。

已有安装可替换原目录文件并在扩展管理页刷新，本地数据会保留。迁移到另一台电脑时，在旧设备打开设置并“导出备份”，再在新设备“导入备份”。
